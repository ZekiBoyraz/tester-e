# tester-e

This repository includes tester-e plugin and other public repositories.

## Claude Code plugin

Claude writes WEB, API, performance and mobile tests for your app, keeps them in your repository
under `.tester-e/`, catalogues them in tester-e as test cases, suites and plans,
and runs them as a regression.

```text
/plugin marketplace add ZekiBoyraz/tester-e
/plugin install tester-e@tester-e
```

Then `/mcp` → **plugin:tester-e:tester-e** → **Authenticate**, and sign in with
your tester-e account. Details: [plugins/tester-e](plugins/tester-e/README.md).
